Snapshot date: **2026-09-29**. This file inventories the complete local working folder
(~80 GB) that existed before it was deleted, so that every excluded artifact can be traced,
regenerated, or recovered. See `docs/HANDOVER.md` for restore instructions.

Sizes are shown in **MB (decimal, 10^6 bytes)** and are rounded; they were measured with:

```powershell
Get-ChildItem -Force -Directory | ForEach-Object {
  $s = (Get-ChildItem -Recurse -Force -File -ErrorAction SilentlyContinue $_.FullName |
        Measure-Object Length -Sum).Sum
  [PSCustomObject]@{ Dir = $_.Name; MB = [math]::Round($s/1MB, 1) }
} | Sort-Object MB -Descending
```
